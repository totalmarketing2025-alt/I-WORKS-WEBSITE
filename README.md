# I-WORKS v4.6 — Fire Eye concept showcase

Static multilingual website for I-WORKS, with no build step. Fire Eye is presented as a concept / pilot-design project.

## Fire Eye concept shown on the site
- Forest and green-space wildfire early-warning network using overlapping wide-angle sectors, a separate optical PTZ verification camera, local AI processing and planned Starlink backhaul.
- Proposed 50 m towers and up-to-20 km² coverage per location are clearly labelled preliminary design targets, subject to vendor and terrain validation.
- The control-panel graphic is illustrative. There are no live Fire Eye towers, sensors, emergency-service dispatch connections or confirmed detection results.
- Camera zoom, coverage, AI performance, network resilience and power must be validated before operational capability claims.

## Existing site limitations
- The page remains a static showcase without a backend or working contact form.
- StellarECC and SARISA panels are illustrative/source-based presentations; they are not live systems.
- HAVOC GUARD camera activity remains fictional demonstration data.
